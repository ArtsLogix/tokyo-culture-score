# 東京カルチャースコア

> 創造 × 場 × 日常浸透の循環モデルで、東京16エリアの文化密度を定量化するインタラクティブダッシュボード

## スコアリングモデル

```
文化度(0-10) = ベーススコア × 0.7 + 多様性スコア × 0.15 + 持続性スコア × 0.15

ジャンルスコア = 創造 × 0.4 + 場 × 0.3 + 浸透 × 0.3
持続性スコア   = 個人店比率 × (1 − 家賃指数/10 × 0.5) × 10
```

## 対象エリア（16エリア）

| タイプ | エリア |
|--------|--------|
| 開発系 | 渋谷・神宮前 / 麻布台・六本木 / 虎ノ門・新橋 / 池袋・東池袋 / 中目黒 |
| 成熟系 | 蔵前 / 三軒茶屋 / 学芸大学 / 吉祥寺 |
| サブカル系 | 下北沢 / 高円寺 |
| ローカル系 | 西荻窪 / 荻窪 / 阿佐ヶ谷 / 鶯谷・入谷 / 小岩・江戸川 |

## データソース

- 店舗数・カテゴリ分類：Google Maps（2024年）
- イベント数：Peatix 年次集計（2023-24年）
- 家賃相場：SUUMO・athome（2024年）
- 浸透度：食べログ 口コミ数・評価点（2024年）
- 個人店比率：各区商工業実態調査（2022年）+ 現地調査推計
- 人口・面積：国勢調査（2020年）
